# backend

Folder untuk kode backend (server) aplikasi absensi.

Rekomendasi:
- Stack contoh: Node.js + Express atau Laravel (PHP)
- Struktur awal: src/, routes/, controllers/, models/
- Tambahkan file konfigurasi: package.json / composer.json, .env.example

Tugas awal yang bisa dikerjakan:
- Tentukan stack backend
- Buat endpoint API untuk autentikasi dan absensi (check-in, check-out)
