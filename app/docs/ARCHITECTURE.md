# Arsitektur dan kebutuhan fitur

Dokumen singkat untuk mencatat arsitektur yang diusulkan dan fitur utama.

Contoh isi:
- Autentikasi: JWT atau OAuth2
- Database: PostgreSQL (direkomendasikan) atau MySQL
- Fitur inti: registrasi pengguna, login, check-in, check-out, laporan kehadiran, manajemen jam kerja
- Integrasi: notifikasi email, export CSV/PDF

Silakan edit dokumen ini untuk menuliskan keputusan arsitektur lebih lanjut.
